# Página completa — Pai-Nosso em Aramaico

Este pacote está pronto para GitHub e Vercel.

## Arquivos

- `index.html`: página completa.
- `assets/hero-pai-nosso-aramaico.png`: imagem usada na página.
- `vercel.json`: configuração da Vercel.

## Publicação

1. Extraia o ZIP.
2. Envie todos os arquivos e a pasta `assets` para a raiz de um repositório do GitHub.
3. Importe o repositório na Vercel.
4. Escolha o preset **Other** e clique em **Deploy**.

Não é necessário instalar dependências, configurar comando de build ou alterar a pasta de saída.

O checkout, o vídeo e o encaminhamento das UTMs já estão configurados no `index.html`.
